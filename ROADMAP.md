# Roadmap

## Working now

- [x] RSS collection from multiple Turkish news sources
- [x] content cleanup, validation, duplicate filtering, and source health logging
- [x] categories, importance scoring, and statistics
- [x] deterministic story clustering
- [x] source-grounded story synthesis with caching and safe fallback
- [x] daily pages, archive, search, and JSON outputs
- [x] responsive editorial website
- [x] optional email newsletter
- [x] source-grounded follow-up questions for a selected story

## Next

- [ ] finish a stable public deployment
- [ ] add end-to-end checks for generated pages and links
- [ ] improve source monitoring and failure reporting
- [ ] add editorial review controls before publication
- [ ] document newsletter deployment and scheduling
- [ ] expand the source list without weakening reliability

## Later

- [ ] Turkish text-to-speech output
- [ ] audio bulletin feed
- [ ] video templates and subtitles
- [ ] automated video publishing

The priority is a reliable, source-grounded news product. Voice and video come after the text experience is stable.
